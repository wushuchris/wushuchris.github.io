# Christopher Mendoza — AI Engineering Lab

Interactive portfolio for Christopher Mendoza, built as a living engineering lab rather than a static resume.

## v1 scope

- 30 Agents for AI Engineers system map
- Current and next build panels
- Recent build history
- Project systems: 30 Agents, F1 IoT Strategy Advisor, AI Robotics, Research & Investments
- System Horizon for future physical-intelligence work
- Optional lab terminal interface
- Responsive layout and reduced-motion support

## Tech

React 19, TypeScript 7, Vite 8, GitHub Actions, GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

GitHub is the source of truth. The `master` branch deploys to GitHub Pages through `.github/workflows/deploy-pages.yml` using GitHub Actions and HTTPS.
